## 1. The fourth artifact input

The model mints artifacts from `data/sources.json`, the generated discovery manifest, the paths the evidence reader hashed, and - from this phase - **audited registrations of externally acquired documents**. The discovery manifest stays its generator's: externally acquired is not discovered by the crawler, and no crawl fact is written.

- `tools/mig_m2_identity.py` reads the manifest's `registration` rows (`external_registrations`) and mints each document by its sha256 through the same call as every other digest, after all of them, so that no existing artifact's id moves when the model is built from scratch.
- `tools/mig_m6_provenance.py` places each at its URL in M3.2B's shape (`external_placements`): a URL locator, the confirmed source, the fetch day, `retrieval_method`, and a DOCUMENT provenance whose `code_state` names the stream, the M3.8 acquisition and `EXTERNAL_ACQUISITION`.
