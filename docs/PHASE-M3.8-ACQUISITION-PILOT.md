## 3. Identity rules

Identity comes from the document's own text: never its URL, filename, folder, the page that linked it, or a publication date. The estate is named in the text (a web address such as durfort-vivens.com is not a naming); the wine is a heading that is the name of a wine the model lists for that estate; the vintage is an explicit statement ("vintage 2014", "2013 vintage", "Jahrgang 2013", "年份2004", or the heading wine's name followed by a year). A year standing alone on a line is layout: it is kept as `bare_year_lines` for the later review and never used. Conflicting statements leave the vintage open.
